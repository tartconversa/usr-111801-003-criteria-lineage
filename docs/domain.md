# 景区资料语义

来源可以是主管部门、景区运营方或合作机构。每份原件有来源、字段说明与摘要，产品修订引用原件，交付时按领取方、用途和来源辖区核对许可。受理人员应能区别来源事实、内部编排和已交付凭据。

当前项目围绕评价标准变更的口径血缘开展资料协作。正式公告、复核观察和运营材料各有发布主体；示例记录不代表真实景区状态。

来源字段目录、数据产品修订和交付回执都必须说明各自采用的评价标准版本。主管部门的项目定义更新后，同一字段名不自动视为同一分数：沿用旧材料前需对照新口径标明可沿用与需重新取证的字段，已出具的结论按原解释保留。标准发布中断或撤回时，已出具的结论与尚未发布的草案分别呈现，供复核人员解释差异。字段级处置见 docs/standards.md。
